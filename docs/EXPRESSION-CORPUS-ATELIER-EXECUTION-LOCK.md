## 0. Core production law

The source world says **what must remain answerable**. The live Atelier determines **how that burden is materially carried**.

```text
canonical authored record / room / whole / relation field
        ↓ exact bounded packet
Khora · Hen · Pleroma · Chronos
        ↓
real Point-Cloud Atelier session
        ↓
Anima composition / material / temporal / integration
        ↓
actual playback / inspection / capture
        ↓
Aletheia witness / critic / curator / praxis
        ↓

        + form occurrences

```

A prewritten scene specification can seed work. It is not the finished artifact.


A packet never authorises an Agent to invent a missing argument, source relation, quotation, citation or canonical edge.

If a bearing relation is not recovered, follow the repository retrieval/effects protocol first.

# II. Family grammar and repetition

## 3. Repeated forms are one grammar with many exact addresses

The source already contains repeated structural families. The Expression corpus should use that fact rather than making each record a bespoke application.

Examples:

```text
A01–A36    → A-family Expression/profile grammar
A′         → conjugate family grammar
C          → concept family grammar
A/C        → root / relation grammar
S          → S-family grammar
rooms      → movement/room grammar
```

Every canonical identity remains independently addressable and retains its exact source/relations.

A family grammar provides continuity; it must not flatten substantive differences between records.

## 4. Profile inheritance

```text
O:I global
→ Epi global
→ Return-of-Zero corpus
→ register / M-family
→ repeated family / branch
→ record authored variant
→ scene-local live override
```

Parent levels may carry:

- material/stage baseline;
- typography/text placement;
- framing/camera grammar;
- particle/form scale and resource budgets;
- motion/transition rhythm;
- reading HUD/aperture conventions;
- portal/fallback conventions;
- reduced-motion/theme behaviour.

Aletheia may later propose profile refinements from repeated actual use. It may not force all source records into one visual treatment merely because it tested well elsewhere.

# III. Graph is the Expression relation field

## 5. One relation state

```text
canonical current record
→ declared bounded neighbourhood
→ exact relation/source/readings
→ ExpressionGraphBinding
→ field/entities/formations/layout
```

Graph/page/minigraph and Expression are presentations of the same source-backed relation field where they share scope.

A selected relation/entity in the Expression carries the same canonical ref used by the Wiki/graph/Nara path.

QL constellation/harmonic layout may organise the supplied relation set where legitimate. It may not create a source edge because two things look adjacent or because completing a form is aesthetically attractive.

# IV. Live visual material arises from the content lane

## 6. No separate advance iconography programme

The corpus does not begin by procuring all images/glyphs for every future scene.

A content lane encounters an actual need while making:

```text
source burden
→ representational/material problem
→ candidate glyph/image/ASCII/diagram/form
→ provenance/rights/source check
→ test in live Expression
→ witness + critique
→ accepted / rejected / retained variant
→ curator occurrence index
```

The admitted visual bank therefore records forms that have actually participated in the work.

## 7. Occurrence relation

For a figure/motif/thing/concept:

```text
subject
→ admitted forms
→ exact Expression/Scene occurrences
→ source/rights/standing
→ practice evidence where present
```

For a form:

```text
form
→ native source / creator / rights
→ subjects/roles it has served
→ all occurrences
→ accepted/rejected evidence
```

A recurring image remains a recurring image, not a fixed definition of its subject.

# V. Mytheme whole-first law

## 8. The whole is primary

The Mytheme register must preserve the whole relational story/work deeply enough that its transformations and ending can qualify its beginning.

A Whole Mytheme may therefore require a real scene sequence rather than one representative image.

The order remains:

```text
source whole
→ whole relational Mytheme Expression
→ internal scene/amplification relations
→ derivative figure/object/motif occurrences
→ cross-story comparison
→ higher constellation where authored/earned
→ Return
```

Derived figures, animals, objects, elements, places, actions, motifs and archetypal readings retain exact reverse links to their whole-story moments. `human-amplified` standing remains visible.

The Atelier's form bank helps compare recurrences without replacing the whole with an icon dictionary.

# VI. Anima / Aletheia in every content lane

## 9. Anima offices

```text
anima.composition
  whole, hierarchy, scene grammar, foreground/background, quiet, sequence

anima.material
  formations, pins, glyph/image/ASCII, density, scale, field, physics, colour

anima.temporal
  duration, transition, camera, automation, focus, morph, performance

anima.integration
  exact source refs, family/profile inheritance, graph/portal relation, final revision merge
```

## 10. Aletheia offices

```text
aletheia.witness
  exact material result, engine/artifact generation, captures, failures

aletheia.critic
  source fidelity, legibility, expressive force, pacing, coherence, excess/understatement

aletheia.curator
  accepted artifact/form/provenance/occurrence admission

aletheia.praxis
  reusable practice candidate, examples, counterexamples, applicability
```

One capable Agent can occupy several offices serially. A complex Mytheme or whole-reading Expression can split them among subagents. The office relation remains attributable in receipts.

# VII. Artistic learning

## 11. Corpus work teaches the modality

A meaningful iteration should retain:

```text
source/content burden
Expression/Scene/Profile/engine basis
Anima actor + office(s)
material/parameter/form/sequence deltas
intended expressive relation
observed result
Aletheia critique
human response where explicitly given
disposition
scope / confidence / unresolved question
counterexamples
```

This evidence is used to learn how the point-cloud medium can disclose relations, not to score the essay aesthetically.

## 12. Colour standing

Every important colour decision records why it is present:

```text
source-backed correspondence
M/register navigation
subject/figure association
affect/mood
material contrast/legibility
experimental association
```

Only a genuinely source-backed relation is source meaning. The rest remain presentational/artistic unless separately grounded.

## 13. Praxis promotion

```text
ExpressionPracticeCandidate
→ reuse on another target
→ works | fails | narrower-than-thought | revised
→ Recognition
→ named Method / Anima Skill refinement
```

The corpus should leave behind a tested craft language, not a single opaque style prompt.

# VIII. Parallel source lanes

## 14. E0 — integration / census / work orders

Owns:

- named source revision and census;
- target-keyed packet builder;
- family/profile registry refs;
- generated Expression coverage inventory;
- Atelier ingress/continuation mapping;
- shared schema/profile conflicts;
- source reconciliation after canonical changes.

E0 does not decide all artistic treatments.

## 15. E1 — essay / section rooms

Carries the reading root, eight rooms/six movements and ordered return through a coherent addressable Expression/scene structure. It preserves the manuscript/room relation without promoting generated rooms over canonical nodes.

## 16. E2–E6 — A / A′ / C / A/C / S

Each lane:

- recovers the entire current family census;
- identifies shared compositional burden;
- establishes a family profile/grammar without pre-fixing local scenes;
- crafts every in-scope record through live Atelier;
- returns exceptions rather than forcing uniformity.

## 17. E7 — Concepts / Episteme repeated forms

Carries concept records and other Episteme page types through typed repeated forms while preserving their exact source/evidential status.

## 18. E8 — Matheme

Develops formal/diagrammatic expressive grammar from canonical Matheme records and their source-backed relations. Diagrams/glyphs are sourced or generated with explicit standing; formal resemblance is not proof.

## 19. E9 — Symbolon

Carries the Symbolon register as the root/whole relation and its heads/spine/traversals. Do not reduce Symbolon to a sibling content bucket detached from its whole-form office.

## 20. E10 — Mytheme wholes

One primary Whole Expression per canonical whole where required, with complete narrative/transformational sequencing and derivative occurrence links.

## 21. E11 — remainder census

Every canonical carrier not claimed elsewhere receives explicit Expression coverage or explicit reason it is non-Expression for this submission cut. No silent leftovers.

# IX. Passes and gates

## 22. P0 — live Atelier enablement + one pilot

Before mass production, prove one real target can:

```text
packet → live AtelierSession → Anima → playback/capture
→ Aletheia → accepted artifact → occurrence/practice receipt
```

The pilot calibrates the protocol, not the style.

## 23. P1 — fan-out

Run E1–E11 in parallel through distinct Atelier sessions. Use target-keyed packets and exact source revisions.

## 24. P2 — source reconciliation

After accepted canonical source changes:

```text
rerun census
→ diff affected identities/relations/readings
→ invalidate affected work orders
→ reopen affected live artifacts
→ revise materially
→ retain valid authored variants
→ report retired/orphan bindings
```

Do not treat stale artwork as current because it still renders.

## 25. P3 — whole-corpus continuity / praxis

Review the complete set for:

- profile inheritance rather than copied constants;
- useful family/register continuity without sameness;
- colour-role standing;
- typography/camera/transition rhythm;
- appropriate use of the full engine vocabulary;
- deliberate quiet;
- Mytheme wholeness;
- source portal Return;
- graph/Expression one-state focus;
- form occurrence/provenance traversal;
- practice candidates with counterexamples;
- no semantic edits hidden inside aesthetic alignment.

# X. Submission closure

## 26. Corpus gate

Corpus closure requires:

- complete/dispositioned coverage against the canonical census at the named revision;
- all four registers present as themselves;
- essay/rooms/argument/concept/S routes represented;
- Whole Mythemes narratively adequate;
- actual Point-Cloud artifacts, not only specs;
- canonical refs retained through graph/Expression/portal relations;
- content-arising forms provenance/occurrence indexed;
- profile continuity reviewed;
- Anima/Aletheia practice exercised and evidenced;
- at least one practice candidate transfer-tested.

This joins, but does not replace, O:I product/runtime acceptance and environmental/material stress acceptance.

Human authorial/creative judgement remains required for final experiential verification.
