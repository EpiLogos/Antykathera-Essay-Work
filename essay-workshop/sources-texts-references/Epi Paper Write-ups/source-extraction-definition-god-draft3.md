# Source Extraction — The Definition of God, Draft 3

## Use boundary

This ledger preserves Frank Taylor's own reusable formulations from the fixed local manuscript [`The Definition of God — Draft 3.md`](/Users/admin/Documents/Nara-Personal/definition-of-god-working/The%20Definition%20of%20God%20%E2%80%94%20Draft%203.md). Every entry below was checked against that file on 2026-07-14; its line locator is therefore ready for **internal quotation and authorial reuse**.

The draft is authorial provenance, not public warrant. Its embedded references to Gödel, Jung, Eckhart, classical myth, Sanskrit sources, topology, physics, AI, or institutional history do not acquire quotation-ready status here. Each entry names that boundary so a strong sentence can be carried into *The Return of Zero* without silently carrying an unverified attribution with it.

The recommended use labels remain deliberate:

- **Extracted / supports** — exact authorial formulation available for reuse.
- **Extracted / qualifies** — exact authorial caution or status boundary.
- **Resonant** — a poetic or mythemic fit; never mathematical, historical, or doctrinal proof.
