# R4 — Eight-station / 48-movement review ledger

**Standing:** live T25 R4 reading and repair evidence. Movement bodies are read in global order. A movement is marked `PRESERVE` only after substantive reading, not because its links resolve. Canonical owners reopen only for genuine semantic defects.

## Review grammar

For each movement record:

- **Pressure** — what the previous movement leaves unresolved.
- **Claim / operation** — the positive move actually made.
- **Envelope** — what belongs in linear prose versus formal plate, source/history inset, visible Mytheme/path or radial dossier.
- **Withhold / payoff** — what must not be spent yet and where it is earned later.
- **Seam / Return** — what the movement hands to its neighbour and how later material returns to it.
- **Disposition** — `PRESERVE`, `REFINE`, or `FOLD-BACK` where a canonical owner must change.

The governing transverse test is: ordinary knower/means/known → mediation becomes explicit → paradigm as lived disclosure → Project as thrown-forth determination → paradox exposes the containing relation → Epi-Logos returns the account into enactment → compassion governs that return. This is a traversal test, not a vocabulary quota.
