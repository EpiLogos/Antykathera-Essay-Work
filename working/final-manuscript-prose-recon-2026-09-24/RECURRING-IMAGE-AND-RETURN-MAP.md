# Recurring image and return map

**Purpose:** the final manuscript should remember itself. A recurring image must not restart from zero merely because a new section begins.  
**Base:** assembled candidate + section SOURCE-RETURNs + WHOLE-PASS-REVIEW narrative homes.

For each: **first work → acquired meaning → later return → what must not be retold → what newly becomes visible.**
