## Governing disposition

P2 enrichment does **not** require quotation saturation. It requires stable source identity and honest readiness boundaries.

Therefore:

1. Existing canonical `SOURCE.md` houses and stable `source_id`s remain the evidence identities.
2. T09 `Depth Restoration: pending` is not evidence readiness. Where the debt concerns source passages, locators, editions or comparison depth, it is now explicitly **OPEN / radial-depth / P2-enrichable** unless this ledger says otherwise.
3. An authorial/Derived/Argued proposition remains strong in its own register. Missing external corroboration never licenses dilution of the proposition; it only limits what may be attributed to an external source.
4. No Open item may be cited as if passage-ready merely because a canonical Argument/Concept names the tradition.
5. A P2 page that needs new external evidence after this lock must reopen/add a source-intake decision rather than silently treating a new web/PDF find as canonical evidence.
6. Protected `NOTES.md` remains read-only.

## T09 Depth Restoration rule carried into P2

All A01–A36 and C01–C64 pages remain `Depth Restoration: pending` where written. That status is **not a P1 failure** and must not be mass-flipped to “restored” at source lock. It tells P2/T22 where deeper derivation, examples, passages, exact carrier recovery or source comparison can increase articulation.

A page may be enriched from existing canonical source houses immediately. If enrichment requires a genuinely new external evidence identity, create/reopen the appropriate source ticket and then fold the result back with typed provenance.

## Source-bank lock boundary

The following are stable input to P2:

- canonical `SOURCE.md` house identity and `source_id` scheme;
- typed distinction among authorial proposition, source warrant, product intent, architecture, implementation fact and Open research;
- T09 A/C/E census and P1 Movement consumer routes;
- existing ready passages/quotations exactly where their source houses say they are ready;
- every debt family above has a named non-silent office.

The following are deliberately **not** claimed locked as ready evidence:

- passage/locator debt named above;
- current product state beyond recorded evidence pins;
- newly discovered external sources;
- any Depth Restoration item whose canonical page explicitly says source verification remains pending.

This is sufficient for P2 field-page enrichment because P2 can deepen the knowledge world without confusing Open research with established warrant.
