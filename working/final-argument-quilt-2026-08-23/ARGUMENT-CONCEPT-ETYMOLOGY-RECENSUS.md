# Argument / Concept / Etymology Recensus

This file is the ratified identity-and-routing census for the rebuilt argument field. It corrects the earlier #39 compression which promoted six cross-field summaries (`CT-01`–`CT-06`) into a new theorem ontology.

The governing distinction is now explicit:

```text
CORE ARGUMENT SPINE
= the load-bearing dependency / traversal through the developed argument field
= realised linearly through the existing 48 Movements

FULL ARGUMENT FIELD
= 36 canonical Argument identities
+ 64 canonical Concept identities
+ Etymology whole-fields
+ Matheme / Mytheme / Episteme depth
= 100 indexed Argument/Concept grounds before those further depth registers unfold
```

The `36 + 64 = 100` count is consonant with the already-authored Second Spanda accounting `6² + 2⁶ = 36 + 64 = 100`; the count is **not** permission to pad or compress the field. Each identity below is retained because the developed corpus supplies a distinct operation or reusable distinction. If later depth recovery shows that an identity has been falsely merged or split, that evidence returns here as an explicit recensus delta.

## What remains stable

- Historical Argument addresses `01–21` remain provenance carriers for the older canonical argument-map layer.
- Global Movements `01–48` remain linear/traversal addresses.
- The 36 `A##` identities below are the canonical **semantic Argument census** for rebuilding; they do not erase the 21 historical addresses.
- The 64 `C##` identities below are the canonical **semantic Concept census** for rebuilding.
- Etymology has its own office: its canonical unit is the whole relational/lexical field, not an isolated word promoted into a Concept merely because the word is philosophically generative.
- Quaternal Logic is a general formal logic and research field. It generates, houses and relates multiple arguments and concepts; it does not swallow those identities.
- The Taylor `Core Theorems — Pithy` surface is a router into the full authorial theorem provenance, including the deeper updated QL/MEF / non-dual-binary files. It is not a replacement theorem layer.

## How to read the tables

**Office** is a routing burden, not a rank:

- **spine** — directly load-bearing in the sovereign argument's dependency path;
- **transverse** — crosses several spine positions/registers and may become locally load-bearing;
- **depth** — carries a developed derivation/warrant that should not be flattened into the line;
- **research/application** — applies and tests the argument in later technical, cultural or Agentworld fields while remaining philosophically consequential.

**Depth route** names the first material that a later enrichment pass should reopen. It is not exhaustive provenance.
