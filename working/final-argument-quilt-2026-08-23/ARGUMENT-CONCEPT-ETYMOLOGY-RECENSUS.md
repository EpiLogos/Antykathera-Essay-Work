# Argument / Concept / Etymology Recensus

This recensus receives the completed Native 026 and Native 027 field and determines the level required before canonical rebuilding. It does not reopen recovery and does not rebuild the final Symbolon corpus.

The stable historical topology remains:

- Arguments `01–21` are provenance addresses.
- global Movements `01–48` are traversal addresses.
- neither numbering system is silently reassigned.
- theorem identity is a distinct architectural layer because several recovered Argument records are warrants, constraints, applications, Mytheme carriers, or historical braids rather than independent core theorems.

The parent relation is therefore:

```text
core theorem / whole relation
        ↕
Argument office and standing
        ↕
Concept reusable distinctions
        ↕
Etymology whole field + exact operation/register
        ↕
source / evidence
        ↕
Section / Movement
        ↕
Return
```

A core theorem additionally carries a projection contract into the already canonical whole-form grammar:

```text
Symbolon unity
    ├─ Matheme — exact/formal determination
    ├─ Mytheme — image/myth/figure performing the same operation
    └─ Episteme — source, history, concept, lexical and evidential standing
```

`Mytheme / Figure` is not a fourth peer architecture beside Argument, Concept and Etymology. It is one internal register of Symbolon.

## Concept census

The current first-class Concept field contains useful domain concepts but does not yet expose all theorem-critical reusable distinctions. The `concepts/index.md` also names several legacy/reference-note objects that do not match the actual first-class inventory. #39 therefore determines a canonical concept dependency layer rather than treating the current index as authority.

Keep as first-class reusable concepts where already earned: `Apoha`, `Bimba–Pratibimba`, `Diaphaneity`, `J-Space`, `Psychoid Number`, `Mathematical–Artistic Image Register`, `Counterfeit Gathering`, `Fusion as Syn's Shadow`, `Agentworld`, `Anthropomorphization`, `Centaur Societies`, `Parasociety`, `Planetary Computation`, `Prompt Thrownness`, `Dimensional Reframing at Zero and Infinity`, and `Compassion as Sensitivity to Origins`.

These Concept homes must link to, not duplicate, the root Symbolon and Etymology authorities.
