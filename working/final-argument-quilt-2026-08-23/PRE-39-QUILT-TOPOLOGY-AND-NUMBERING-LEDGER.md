## 0. Governing rule

The later quilt is not a new outline laid over the recovered corpus. It is the point at which the **already numbered arguments, concepts, etymological whole-fields, Mythemes, sources and section movements are made mutually inspectable as one authored relation**.

The handoff therefore has to preserve three kinds of identity at once:

1. **stable carrier identity** — argument number, movement number, canonical concept home, etymological cluster path;
2. **semantic office** — what the carrier means in its active relation / Context Frame and why that distinction exists;
3. **provenance and standing** — authored position, design/argument commitment, research proposition, source-backed warrant, implementation/process fact, authorial-only delta, or inference.

No later synthesis earns the right to erase one of those identities merely because a tidier global description is available.

# 5. The crosswalk the fresh-session quilt must produce

For every numbered **Argument 01–21**, the eventual full quilt needs an inspectable row or graph edge set containing at least:

```text
Argument ID / canonical path
→ exact claim and standing
→ source / evidence carriers
→ Concept homes consumed or instituted
→ Etymology cluster + exact operation/register consumed
→ Mytheme / Figure where the argument takes imaginal form
→ Section / global movement consumers
→ transverse threads / neighbouring arguments
→ unresolved authorial, source, or conformance delta
→ final burden office: linear-essential / supporting-visible / radial-depth / whole-form-Mytheme
```

The reciprocal audit then runs from the other registers:

```text
Concept
→ one canonical home
→ arguments and movements that consume it
→ sources / status / confusions

Etymological whole-field
→ operations actually consumed
→ arguments / concepts / Mythemes / sections
→ evidential register retained at every use

Movement 01–48
→ arguments it advances
→ concepts it uses
→ etymological / Mythemic / source relations it actually needs
→ what it hands to the next movement
```

A relation missing from this crosswalk is not automatically missing from the essay. It is first a **retrieval/conformance requirement**. The fresh-session phase should recover it before proposing new architecture.

# 7. Fresh-session boundary — when to generate the execution prompt

The full Argument ↔ Concept ↔ Etymology ↔ Section quilt should be executed in a **fresh session**. Do **not** generate that prompt merely because this topology ledger exists.

Generate the fresh-session prompt only when the live programme reaches the actual handoff boundary:

1. Native 027 / #50 has received the genuinely authorial delta still reserved to Frank, or those items have been explicitly ratified/deferred by him.
2. Native 026 / #48 has completed its current conformance/cold-return pass and can hand a stable field to #39.
3. The current-main topology has been re-read immediately before handoff: Argument IDs, section/movement ranges, Concept canonical homes, Etymology clusters, and any newly admitted carriers.
4. Known stale projections have been repaired or explicitly marked non-authoritative. The Bimba gloss in `concepts/index.md` is the current exemplar of the discipline: found as drift, repaired against its canonical home, then returned here as resolved rather than left as stale audit residue.
5. #39 is ready to be executed as the **one architecture/quilt phase**, rather than being anticipated piecemeal in the preceding conformance work.

At that exact boundary, the prompt must instruct the fresh session to begin from current live state and to run the **Unslop discipline as a hard condition of the work**:

- read/audit before rewriting;
- remove generic transitions, repeated significance claims, audit/recovery residue and canned rhetorical contrasts;
- preserve facts, provenance, uncertainty, native technical terms and authored distinctions;
- do not convert architecture into prose-shaped filler;
- maximise recoverable relation per sentence;
- never manufacture an inferior hypothetical framing merely to demonstrate that the established framing is better.

The fresh-session prompt is therefore an **output of reaching the boundary**, not a document to freeze in advance while the field is still changing.
