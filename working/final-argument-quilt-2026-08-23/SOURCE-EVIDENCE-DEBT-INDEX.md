# 0. Debt-record law

Each debt names:

| field | meaning |
|---|---|
| proposition | exact claim or relation needing support |
| theoretical status | authored position / native derivation / research proposition / inherited claim |
| debt type | source-location / quotation / edition / philology / empirical evidence / provenance / etc. |
| current source state | what already exists |
| completion task | smallest sufficient next action |
| target office | where the completed evidence returns |
| blocking scope | what it actually blocks |

A debt blocks **only** the attribution/use that depends on it. It does not downgrade a distinct native derivation or authored synthesis merely because an external witness is incomplete.

# Return rule

When a debt is completed:

1. update the exact source house/passage card;
2. update the consuming argument/concept/etymology/Mytheme/Matheme relation;
3. change this record's source state rather than deleting its history;
4. preserve whether the source **grounds, qualifies, contradicts, resonates with, or merely contextualises** the project-native relation.

Source completion increases the field's answerability; it does not become the author of the native derivation it supports.
