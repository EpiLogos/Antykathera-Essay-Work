# The Quaternal Logic Tarot Journey: Complete History & Context

## Overview

Two decks. One continuous journey. Each draw consists of 6 cards (except where noted) occupying Quaternal Logic positions #0–#5. The deck was shuffled once per deck; draws were taken sequentially when felt right. All readings use the Thoth Tarot (Aleister Crowley).

### QL Positional Key
- **#0** — Archetypal Foundation (void-ground, implicit assumptions)
- **#1** — Causal/Material (substance, what-is, material cause)
- **#2** — Logical/Methodological (epistemology, how-we-know, efficient cause)
- **#3** — Processual/Ontological (becoming, unfolding, formal cause)
- **#4** — Meta-Epistemic/Contextual (purpose, telos, final cause)
- **#5** — Divine-Scalar/Synthetic (integration, synthesis, completion)

### Structural Principles
- Even positions (0, 2, 4) = Adam axis (structural, stabilising)
- Odd positions (1, 3, 5) = Eve axis (generative, dynamic)
- #0 and #5 are implicate (framing); #1–#4 are explicate (working)
- #5 returns to #0 via Möbius twist (synthesis → new ground)

### Reading Topologies
- **Torus**: Standard 6-fold reading (the draw as it presents)
- **Lemniscate**: Nested 6-fold within the #4 position of a prior draw (unpacking purpose)
- **Klein Surface**: Inverse analytical reading (shadow/underside of a torus reading; the two co-present as one non-orientable surface)

### Notation
- ᴿ = Reversed
- T = Trump (Major Arcana)
- Kn = Knight, Qu = Queen, Pr = Prince, Pri = Princess
- W = Wands, C = Cups, S = Swords, D = Disks
