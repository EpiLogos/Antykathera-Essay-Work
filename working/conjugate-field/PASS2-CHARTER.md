## 2. Composition law (load contract observed)

Before drafting anything, read — and only — `writing-guidance-tools/references/WRITING-LAWS.md` and `writing-guidance-tools/references/WRITING-RUBRIC.md`, then the actual source and carrier material governing each record. Do **not** open fault-calibration, authentic-voice-reference or writing-style-reference.

The order, never reversed:

```text
recover whole / actual argument
→ determine the page's exact office
→ map claim, operation, dependencies and Return
→ write substantive top-level prose
→ add routing / metadata around that prose
→ audit against the rubric
```

Applications:

- **The swap test.** If a paragraph could be moved into another node's same-numbered section without loss, it is filler and dies. The sixfold structures disclosure; each section must contain what only this argument, at this position, discloses.
- **Write less per section.** A section with one true sentence gets one true sentence.
- **No name-drop glosses.** The negative exemplar is fixed: *"The binding is an operation with an owner."* A primitive name followed by abstract generality is not prose. Signal a reader can receive, or nothing.
- **Examples judge existing prose; they never generate the argument.**
- **Plain-English receipts and final reports.** Narrate what was done and why in sentences a person reads; inventories are for tables inside receipts, never for prose or reports.
