# Antikythera Essay Structure Legacy

> [!warning] Archived provenance
> Nothing in this folder governs the current draft. The sole live structural authority is [[The Return of Zero — Central Argument Plan]]. These materials are preserved because they contain useful phrases, references, visual experiments, and records of how the argument changed.

## v1 — Evidence-network architecture

The first version organised the essay as a dense graph of sections, claims, images, quotations, and research vectors. It remains the most granular record of the early source wiring, but its mechanism-led sequence and graph density have been superseded.

## v2 — Voice-and-station architecture

The second version separated continuous conceptual voices from sequential stations and added a three-tier reader. It improved readability but retained the older opening and mixed argumentative levels too freely. Its cards remain useful as a lexicon and phrase bank.

## How to use this archive

Mine it for evidence, language, objections, and visual ideas. When an archived element is revived, rewrite or relink it into the v3 structure rather than treating the old location as current. Any proposed change to the essay's governing sequence belongs first in [[The Return of Zero — Central Argument Plan]].
