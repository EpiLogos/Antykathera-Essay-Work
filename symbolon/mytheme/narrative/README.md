# Narrative

Narrative houses sequences whose order carries philosophical work: fables, encounters, case narratives, cultural stories and composed passages that cannot be reduced to a static symbol. Their movement reveals how a distinction is made, inhabited, reversed or returned.

A record marks the beginning state, decisive turns, achieved transformation and remainder. It identifies whether the narrative belongs to Frank, to an external work or to a documented encounter. Argument links attach to exact turns rather than to the title as a whole.
