# Sources

Sources contains the public source houses that bear the essay. The internal path remains stable and meaningful:

```text
sources/<epistemic-domain>/<author>/<source-id>/SOURCE.md
```

One `SOURCE.md` holds bibliographic identity, citation forms, source teaching, exact passages, locators, verification, provenance, use boundaries and consumers. Passage text has one canonical transcription. Public source houses exclude Frank's private sibling `NOTES.md`.

Each use declares whether it is Extracted, Paraphrased, Argued from or Resonant with. Citation readiness, quotation readiness and the essay's claim status remain independent. Source IDs resolve through the repository resolver and never through an assumed nesting depth.
