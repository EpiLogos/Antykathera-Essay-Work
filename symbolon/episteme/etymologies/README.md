# Etymologies

Etymologies carries word histories where the movement of a term changes the argument. Active braids include symbol, account and trust; apportionment and economy; homology and analogy; and encounter, region, name and count.

Each record separates attested linguistic history from the essay's philosophical reactivation. Forms, dates, languages and sources establish the history; the essay then argues what an inherited relation can disclose now. Etymology opens an operation and cannot settle a claim merely by origin.
