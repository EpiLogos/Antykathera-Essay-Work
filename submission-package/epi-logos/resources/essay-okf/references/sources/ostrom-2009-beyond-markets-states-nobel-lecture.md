# Ostrom — Beyond Markets and States (Nobel Lecture, 2009/2010)

## Essay use

An empirically informed vocabulary for participation, recognized local rule-making, and nested governance. It contextualises conditions that a proposed sovereign commons would need to design and test.

**Claim boundary:** this lecture does not verify 4:2 Technē, QL, AHI, shared hardware/data architecture, or any implementation outcome.
