# Contract Examples

These files are validated examples of the machine contracts in `../contracts/`.

- `minimal-ql-frame.json` — a complete twelve-address structural shell with latent occupancy and a valid `P5′→P0⁺` return.
- `minimal-render-plan.json` — an eight-second, 24 fps base plan with six reciprocal pairs, twelve atoms, exact symbol/type layers, canonical audio, and loop requirements.
- `action-request.json` — a valid `ql.map` action request envelope.
- `seedance-provider-capability.json` — a dated reference capability record based on official Seedance 2.0 material. Production MUST refresh and approve provider capabilities before use.
- `minimal-package-manifest.json` — a schema-valid `.epicard` inventory showing immutable revisions, disclosure projection, entrypoints, renditions, per-file hashes, and the path-sorted root digest contract.

The examples illustrate shape and invariants. They do not prescribe symbolic content, Pasu data, or art direction for a real engagement.
