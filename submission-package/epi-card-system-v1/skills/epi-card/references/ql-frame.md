# Canonical QL frame reference

## Traversal

```text
Threshold 0/1
P0 Truth → P1 Mind → P2 Word → P3 Logos → P4 Son → P5 Image
P5 → P0′ Klein twist
P0′ Play → P1′ Need → P2′ Sacrifice → P3′ Decision → P4′ Love → P5′ Work
P5′ → P0⁺ enriched return
```

`P0⁺` is the next engagement tick's `P0`, not a thirteenth position.

## Relations

- Conjugates: `Pn↔Pn′` for n 0–5.
- Complements in each phase: `0↔5`, `1↔4`, `2↔3`.
- 4:2 partition: positions 1–4 explicate; 0 and 5 implicate.
- 3:3 partition: `1,2,3 / 4,5,0` in each phase.
- The card's six hexagonal edges each present one conjugate pair.

## Occupancy

Allowed states: `present`, `latent`, `missing`, `unknown`, `withheld`, `conflicted`, `overdetermined`.

A source member must have one or more explicit assignments or a global `unassigned` assignment. Mapping roles are `direct`, `distributed`, `condensed`, `supporting`, `counterposed`, and `unassigned`.

## Registers

`exact_identity`, `ql_derived`, `canonical_symbolic`, `cross_register`, `archetypal_reception`, `open_extension`.

Do not replace a register with a confidence score. Register says what kind of relation is claimed; confidence says how strongly the present run supports it.
