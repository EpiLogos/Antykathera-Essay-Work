# Resonance-frequency reference

The universal coordinate is dimensionless:

```text
Φ = (θ, ρ, τ, a, c, β, p, R, E, C)
```

- `θ [0,1)`: cyclic phase.
- `ρ ∈ ℝ`: logarithmic register/scale.
- `τ ≥ 0`: pulse/event density per tick.
- `a [0,1]`: amplitude/salience/expressive force.
- `c [0,1]`: coherence/harmonicity/order.
- `β [0,1]`: bandwidth/complexity/inharmonic spread.
- `p [-1,1]`: Bimba–Pratibimba polarity.
- `R`: exact rational interval/proportion set.
- `E`: normalised elemental vector under a named profile.
- `C`: normalised chakra vector under a named profile.

Physical Hz, colour hue, orientation, typographic rhythm, camera pace, and other media parameters are modality projections. Never equate them without a pinned projection profile and receipt.

The reference musical substrate uses Bimba offsets `0,2,4,6,8,10` and Pratibimba offsets `1,3,5,7,9,11`. Corresponding conjugates are a semitone apart in this profile; the within-helix complement mirror is a tritone. The ratio canon includes `1/1`, `9/8`, `4/3`, `3/2`, `16/9`, `2/1`, and their directed reciprocals where specified.

Aggregate `θ` with a circular mean. Aggregate scalar components with bounded weighted transforms. Reduce ratios to canonical rational form. Normalise E and C independently. Persist every contribution and exact profile version.
