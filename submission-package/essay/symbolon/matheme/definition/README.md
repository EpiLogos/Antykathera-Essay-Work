# Definition — the 0

This folder carries what the matheme *is*. It projects File 1 of the Binary Explication ([source house](../../episteme/sources/internal-corpus/taylor/taylor-2026-binary-explication/taylor-2026-binary-explication.md)) with that file's own structure, whose sections spell out the short chain: `§0/1 → §0 → §1 = 4+2 → §2 4+2 → §3 = 5→0 → §4 5→0 → §5 = 0/1 → §5→0`.

## Projected structure (the file's own headings)

- **[the-matheme](the-matheme.md)** — opens with the question "How is it that I am present to my experience?" and earns `0/1` from lived grammar, passing from "I see x" to "I am aware of the seeing of x". It carries the Lacanian genealogy and the M1 address.
- **[minus-over-minus](minus-over-minus.md)** — `−/− = AND/OR / X/x`, the bare logic of differentiation, in which the slash makes one mark into two.
- **[copula](copula.md)** — derives `=`, `/` and `≠` graphically, expands the slash as `/ = ( = =/≠ ≠ )`, and carries the subject–object reading `Ø/X` and `(0/Ø)/(1/X)`.
- **[harmonics-and-recount](harmonics-and-recount.md)** — counts `4+2=6`, recounts it as `4+2 → (3+1)+2`, sets out the three harmonics (Being, Becoming, Knowing/unKnowing) and compresses them to `( = /) : (=/≠ ()) : (≠ =)`.
- **[six-determinations](six-determinations.md)** — derives the determinations line by line through the poem: Ground `0/1`, Definition `?/!`, Dynamis `−/+`, Pattern `X/x`, Context `AM/IS` and Real-isation `∞/dx`. The parent `−/−` and the return `1/0` bracket these six, and together they make the eight.
- **[catuskoti-crossing](catuskoti-crossing.md)** — works the four corners IS, IS-NOT, BOTH and NEITHER, and **SILENCE** as the recognition of all four, around the sentence "0 IS AND/OR IS-NOT EQUAL TO 1". It also reads the vinculum as a fraction.
- **[immutable-subject](immutable-subject.md)** — gives the witness-argument through `0`, `Ø`, `X`, `Ø/X` and `(0/Ø)/(1/X)`, together with the charitable cogito (line 47, indexed CT-16) and *isoid*, a coinage the source flags.
