# Diagrams

This domain holds diagrams whose arrangement performs formal work: derivation trees, determination fields, polarity and slash diagrams, topological maps, covering-space views, harmonic cycles and computational schematics.

Each diagram has a Markdown record and its editable or rendered asset together. The record names the proposition visualised, inputs, transformations, invariant, proof boundary, essay blocks, caption, alt text, source dependencies and rights. A diagram may simplify presentation; it may not omit a step that the claimed conclusion requires.

Narrative and artistic compositions belong in [[../../mytheme/plates/README|Mytheme plates]]. Evidential timelines and source figures belong in [[../../episteme/figures/README|Episteme figures]].
