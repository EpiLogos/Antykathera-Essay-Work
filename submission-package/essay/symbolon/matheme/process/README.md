# Process — the /

This folder carries what the matheme *does*. It projects File 2 of the Binary Explication ([source house](../../episteme/sources/internal-corpus/taylor/taylor-2026-binary-explication/taylor-2026-binary-explication.md)) with that file's own structure. The file's opening heading carries the full chain, `0/1 = 4+2 = 5→0 = 1/0 = 4′+2′ = 5′→0′ = 0/1`, and the segment `= 1/0 =` is earned here.

## Projected structure (the file's own headings)

- **[t1-geometry](t1-geometry.md)** — "AND + OR — The Geometry of Space-Time". It derives the six positions from binary strings and sets out the E→W diametric leap, interval-gluing (`0/1` as the generative operation of closed form), the 75% gap and the squared circle `⃞ + 𐀏`.
- **[phase-flip](phase-flip.md)** — `§1/0 — 0/1 = / ≠ 1/0`, the hinge of the file. It follows Spencer-Brown's re-entry into oscillation, memory and time, and it reads T1→T0 as the passage from third person to first person, from IS to AM.
- **[t0-onto-logic](t0-onto-logic.md)** — "AND/OR — The Onto-Logic". It holds the slash-form table (`0/0 = %`, `0/1 → 0%`, `1/0 = ?/!`, `1/1 = 100%`), the placement of `?/!` at #3, chirality, and the primed positions `#0′–#5′`.
- **[spanda](spanda.md)** — both Spanda equations, with the T0 emanative arc and the T1 reversionary arc, and it projects into [[symbolon/matheme/spanda/README.md|Spanda]].
- **[ratio-threshold](ratio-threshold.md)** — derives 16/9 = (4/3)² (the doubled fourth), (2/1)/(16/9) = 9/8 (the epogdoon) and the four directional ratios. In the file's words, "None of these is imported from music theory. Each is a face of the base frame's own factorisation."
- **[harmonics-symmetries](harmonics-symmetries.md)** — sets Mono-Poly as Becoming, Self-Identity as Being and Number-Word as Knowing/unKnowing, and works the three symmetries, the two axes that cross at #4, and perspectival counting.
- **[ql-positions](ql-positions.md)** — consolidates the QL positions table (§5′), reads pramātṛ, pramāṇa and prameya as numerator, slash and denominator, and gives the naming of Quaternal Logic and Epi-Logos.

The linked records keep the load-bearing headings. The prime glyph here means **inverse-phase positions**, and File 3's Night-pass usage is a different sense of it (see the register README, Two locks).
