# Chronic — Configuration and Passage

## #0 — Two questions about one movement

A synchronic reading holds a configuration together, and a diachronic reading follows how it formed and how it changes. [Symbolon Dynamics](../../episteme/sources/internal-corpus/taylor/taylor-2026-symbolon-dynamics/taylor-2026-symbolon-dynamics.md) **sources** this landscape/trajectory pair as operative within objective internality, and [C50](../../../section-rooms/arguments/concepts/C50-Dia-Syn.md) **defines** it as a different pair from the logical cut and gather.

The input is a field with states and possible transitions. A current state is not the field's whole history, and a succession of states does not by itself state the field's rules, so each reading tells us what the other leaves out.

## #1 — Display the configuration

For an elementary mathematical example, take the map `f(x)=x/2` on the real line. The state-space, update rule and fixed point 0 define one configuration of possibilities. Every real starting value converges to 0 under repeated application. This is a simple attracting fixed point, not a strange attractor.

The synchronic view states this organisation without choosing one initial value, since it holds all the possible trajectories together under the rule. In the authorial psychic application a landscape does the same work: it makes the active basins, the boundaries and the available transitions legible together. Modelling an actual psyche that way needs its own warrant, which the fixed-point example does not supply.

## #2 — Follow a trajectory

With initial value 8, the successive states are `8,4,2,1,1/2,…`, or `x_n=8/2ⁿ`. With initial value −4, they are `−4,−2,−1,−1/2,…`. The same organisation permits different histories. Neither finite list exhausts the basin, and the basin does not specify which starting point occurred.

If the rule changes during the history, the configuration itself changes, and the trajectory then needs an account of its changing parameters and conditions. The source's claim about objective internality gives memory, tools, affect, institutions and environment constitutive roles, so an encounter can alter what becomes available next.

## #3 — Cross temporal and logical readings

| Reading | Retained relation | Severed relation |
|---|---|---|
| Synchronic | Configuration includes its conditions and distinct terms | Opposed terms are displayed with their common condition suppressed |
| Diachronic | Change carries provenance, exclusion and return | Successive determinations conceal the field from which they arose |

Crossing the two pairs is the page's principal operation. A cut can be productive at either time-scale and a gathering can fail at either. A photograph-like schema that shows two camps and hides the field that made them is Dia in its severing form, and a narrative that carries its provenance and its exclusions gathers, so neither temporal reading settles by itself whether a relation was retained.

## #4 — Distinguish invariance, interpretation and coincidence

An invariant set in dynamics is a technical object defined relative to a specified evolution. An archetypal ordering capacity and its singular manifestations are the source's Argued psychic refraction of the same shape. The formal example shows how different trajectories belong to one organisation, and what it licenses is that shape. That every psychological recurrence is governed by a measured dynamical system would need a measurement the example does not contain.

Synchronicity is a third thing: meaning recognised across events whose causal histories are distinct. Interpreting it takes its own psychic and historical source work, and it cannot be read off synchrony as a time slice or off a theorem about the fixed point of `x/2`.

## #5→0 — Return the path to the changed field

Two records result: which configuration permitted the movement, and which movement actually occurred. A return can then ask whether the field stayed fixed, which conditions changed, and which future transitions the achieved history now enables.
