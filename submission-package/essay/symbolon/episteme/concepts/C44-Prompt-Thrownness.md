# C44 — Prompt Thrownness

**Definition.** Prompt Thrownness names the condition in which an artificial agent begins an act already situated within a prompt/context field it did not wholly author: system instructions, conversation, memory, tools, role, permissions, training and environment establish an inherited horizon of possibility.

The distinction exists to prevent generated language from being read as if it originated from an unconditioned speaker. It makes the agent's context constitutive rather than decorative, while also avoiding the opposite mistake of reducing every output to one prompt string.

Its operation is **arrival into authored/inherited context → bounded action-space → local interpretation/action**.
