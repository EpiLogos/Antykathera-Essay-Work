# C27 — Protected Account / Occupied Zero / Source-Claim

**Definition.** A Protected Account is a determinate account whose governing criterion is insulated from the encounters that could revise it. **Occupied Zero** names its QL office-confusion: a local `1` acts as though it were the uncounted source `0`. **Source-Claim** names the assertion, implicit or explicit, by which that occupation is justified.

The distinction exists because many pathologies share this structure while differing in content. Complex, metric, institution, ideology or model can all protect a local measure by hiding the conditions through which that measure arose.

Its operation is **local account → criterion protection → source occupation**. C28/C29 give the legitimate source/office alternative; C47 Deferential Intelligence reopens the account to model-revising encounter.
