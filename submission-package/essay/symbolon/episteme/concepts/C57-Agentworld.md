# C57 — Agentworld

**Definition.** Agentworld is a persistent world of positions, artefacts, memories, permissions, tools, models, people and artificial agents in which actions by one participant can become constitutive conditions for later actions by others. It is a worldhood concept, not a synonym for a multi-agent chat.

The distinction exists because isolated-agent descriptions miss the shared field through which agency acquires continuity and consequence. An agent's operative interior can include project state, source graphs, delegated powers, institutional rules and traces left by other agents; those same actions alter the environment inherited by successors.

Its operation is **instantiate situated agents within persistent shared worldhood → let actions change common conditions → preserve provenance/local offices across recurrence**.
