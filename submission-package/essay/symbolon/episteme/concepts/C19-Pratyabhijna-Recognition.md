# C19 — Pratyabhijñā / Recognition

**Definition.** Recognition is return in which a present determination is known in relation to the source, identity or history from which it had become estranged, without cancelling the difference acquired in the interval. *Pratyabhijñā* remains source-specific to the Śaiva recognition tradition.

The distinction exists because return can otherwise be imagined as regression to an untouched beginning. C19 preserves transformation: what returns is not simply what departed, because the path has become part of the relation.

Its operation is **recognise provenance through changed form**. C06 Copula makes identity-through-difference possible; C34 Individuation gives a long-form psychic process; C64 Paradox names cases where recognition changes the containing field rather than solving one side against another.

Nearest neighbours are C34 Individuation, C36 Complexio Oppositorum and C48 Trust. Its counterfeit is recognition forced by a protected account that only accepts what already fits.
