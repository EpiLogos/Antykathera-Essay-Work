# C24 — Fusion

**Definition.** Fusion is the counterfeit operation in which relation is preserved only by erasing the distinctions through which the terms could genuinely meet. It is unity without difference.

The distinction exists because calls for wholeness can be as destructive as absolute division. A sym operation that simply collapses terms prevents answerability: if no distinction remains, no source, Other, error or return route can be discriminated.

Its operation is **relation → difference-erasure → counterfeit unity**. C06 Copula offers the positive alternative: identification through difference. C50 Dia/Syn keeps distinction and return conjugate. C36 Complexio Oppositorum similarly contains opposites without pretending they have become one undifferentiated term.

Nearest opposite failure is C23 Severance; nearest positive neighbours are C06 and C36.

**Argument consumers:** A02, A13, A18–A21, A27, A35. **Movement consumers:** copula, Dia/Syn, individuation and cultural-return movements.

**Etymology relation:** *Homologia / Analogia*; negative operation: univocal merging replaces agreement/proportion among distinct terms. Register **3**. Return C24 → C06/A02 → C36/A21 → C24.

**Source/tradition standing:** authorial failure grammar primary; psychological, mystical and political “fusion” usages are comparative only.
