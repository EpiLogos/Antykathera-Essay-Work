# C55 — Reflective Field / Mirror That Moves First

**Definition.** A Reflective Field is a field in which representations, judgments or agents feed back into the conditions that will generate later representations and judgments. **Mirror That Moves First** names the local case where the reflection alters the next encounter before the source field has otherwise changed.

The distinction exists because models are not always passive pictures. Recommendation, prediction, governance, self-image and generated language can change attention and action, making the model part of the world it later models.

Its operation is **reflect → act/mediate → alter shared conditions → receive a new reflection from the changed field**.
