# Computational Vimarśa

> [!summary]
> Functional capacity of an artificial system to bend its own articulated products back upon their prompts, sources, exclusions, lenses, evaluations, and consequences.

## Boundary

This is an **Argued functional analogy** to [[Vimarśa]], not a claim that computational recursion is luminous self-awareness. It operationalises the inspectable `/` while leaving the subject-pole unclaimed.

## Minimum implementation

1. preserve the selected claim and relevant excluded field;
2. expose prompt, source, lens, evaluator, and preference baseline;
3. generate a counter-reading or inverse traversal;
4. state what the current frame cannot settle;
5. return the revised determination with provenance intact.
