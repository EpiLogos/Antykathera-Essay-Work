# The Blind Spot — Frank, Gleiser, Thompson

> [!summary]
> Adam Frank, Marcelo Gleiser, and Evan Thompson diagnose the “surreptitious substitution” by which scientific abstractions are treated as more real than the direct experience that makes observation and justification possible.

**Master context:** [[The Return of Zero — Central Argument Plan#§0/1 · #3 — The formal-limit genealogy: paradox, incompleteness, silence, creativity]].

## Core diagnostic

The visual blind spot contains the optic nerve; the scientific blind spot contains lived experience. Experience is not another datum missing from the model. It is that by which data, instruments, measurements, and reasons appear and become available at all. The substitution occurs when a model constructed within this field becomes the supposedly more real world to which experience is reduced.

## QL placement

- **Extracted:** scientific concepts are effective abstractions but become distorting when substituted for the experienced world that grounds them.
- **Argued:** the blind spot is the `0` or kartṛ-pole present-by-presupposition and refused as an object of inquiry.
- **Offered:** QL's `0/1` is an architectural completion of the book's diagnostic because it places model and experiential ground in one asymmetric relation.

The book is strongest as a contemporary scientific ally for the problem. It must not be made to endorse QL, Kashmir Śaivism, or idealism unless the text explicitly does so.
