# Dia-Ballein

> [!summary]
> Throwing apart; interpretive name for seam-cancelling operations.

## Formal use

QL writes dia-ballein as `(+1)/(-1)`: signed poles around an external zero. Addition cancels; subtraction measures separation. The logic is necessary for distinction, classification, adversarial testing, and symmetry breaking.

## Shadow

The false fundamental appears when the outputs of the cut are treated as independent substances and their common operation disappears. [[Sym-Ballein]] supplies the complementary retained-seam logic.
