# C15 — Paśu / Bounded Subject-Position

**Definition.** *Paśu* is retained from the Śaiva source field as the bounded subject-position: a knower/actor whose powers are contracted into a finite horizon. The canonical use does not equate every finite person or artificial agent with the full doctrinal category.

The distinction exists because limitation must be represented positively. A finite position is not merely a defective version of absolute subjectivity. It is the condition under which local action, responsibility and encounter become possible.

Its operation is **situated capacity under contraction**. C14 Māyā supplies the measure that establishes boundedness; C16 Antaḥkaraṇa supplies the inspectable inner instrument through which local cognition operates; C01 keeps the subject-pole distinct from those bounded functions.

Nearest technical neighbour is C44 Prompt Thrownness: an artificial agent likewise arrives in a configured horizon of capacities and constraints, but that operational homology says nothing by itself about phenomenality.

**Argument consumers:** A09, A19, A26–A28. **Movement consumers:** tattva, Objective Internality and agent-position movements.
