# C39 — Meta-Epistemic Framework

**Definition.** The Meta-Epistemic Framework (MEF) is a framework for conducting inquiry with explicit lenses, sources, gauges, judgments and return. It is **not** a canonical Argument and not an ontological primitive.

The distinction exists because the essay needs a reusable method for investigating claims across formal, historical, technical and experiential fields without allowing the framework to become the source of what it measures. MEF organises inquiry; it does not prove the ontology it investigates.
