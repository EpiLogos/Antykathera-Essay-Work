# Concepts

Concepts holds the controlled distinctions the argument repeatedly consumes. After T09 the canonical semantic identity surface is **C01–C64**:

- [[CANONICAL-INDEX|Canonical Concept Index — C01–C64]]
- [[../arguments/README|Canonical Arguments — A01–A36]]
- [[../etymologies/T09-A-C-E-RECIPROCITY-INDEX|A ↔ C ↔ E Reciprocity Index]]

Each C-ID page gives a positive definition, the reason the distinction exists, its operation and consequence, neighbours/conjugates, Argument and Movement consumers, load-bearing Etymology relation, source/tradition standing, carrier disposition, unresolved delta and Depth Restoration status.

A Concept is an Episteme record, not a Matheme, Mytheme or Symbolon root. It institutes a reusable distinction; it does not derive a formal operation, perform a whole imaginal scene or claim historical warrant it does not possess.
