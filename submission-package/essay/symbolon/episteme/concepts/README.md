# Concepts

Concepts holds the concept nodes: controlled definitions of the terms the argument does work with, together with each term's exact function in the argument, its differentiations and common confusions, its section and argument consumers, its sources, aliases, and status where the concept carries a claim.

A concept node is an epistemic record, not a matheme, mytheme, or symbolon record. It institutes a term's meaning and tracks where that meaning is used; it does not derive a formal operation, perform an imaginal scene, or hold the root relation. When a concept's definition is load-bearing, the definition stays here and the essay or movement points to it.

The register keeps Concepts distinct from Maps. Maps expose declared structures and routes built from canonical relations; Concepts are the definitions those structures presuppose. Distinct from Dialogues: a concept carries what the argument has accepted; a dialogue records how an idea was formed and never becomes evidence on its own.
