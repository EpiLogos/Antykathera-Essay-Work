# A28 — Authored Ground / Positional Delegation

**Standing:** canonical semantic Argument.

## Argument

No delegated agent begins from nowhere. A position is authored before it is occupied: goals, permissions, vocabularies, evaluation criteria, tools, memory, role, interfaces and inherited obligations establish a ground from which later action becomes intelligible. “Authored ground” names this prior field without implying that the author controls every consequence. “Positional delegation” names the act by which another agent is authorised to operate from a bounded part of that field.

The distinction is essential because delegation easily obscures authorship. Once an agent can act with some autonomy, its outputs may appear self-originating. Yet the operative position was already shaped by selections that came from elsewhere. A system prompt, policy, institutional role, legal mandate or project brief may disappear from the visible output while continuing to determine what the agent can see and do. Objective Internality makes this causal fact part of the interior itself: delegated ground is not metadata outside the agent but one constituent of its worldhood.

Authored ground is not absolute ground. The person or institution that authors a local position is itself situated within wider histories, languages, material conditions and covenants. The relation is recursive. A project can be Bimba for an agent's local context while remaining Pratibimba relative to a wider social or material field. What matters is that each level states its office instead of silently escalating local authorship into source authority.

This makes positional delegation a positive alternative to both command-and-control and fictive autonomy. The delegate receives real scope to judge and act; the author remains responsible for the conditions delegated; both remain answerable to consequences returning from the world. A genuinely agentic system is therefore not one in which authorship disappears, but one in which authorship, delegated discretion and return are separately visible.

## Pressure and distinctness

A25 establishes derivative authority; A26 makes context constitutive of agency; A27 refuses possession of the Other. A28 applies all three to authored positions. It is distinct from A29, which treats power and delegated labour more broadly, and from C44 Prompt Thrownness, which names the agent's situated arrival into an already configured field.
