# A14 — Computational Process Ontology

**Standing:** canonical semantic Argument; historical Argument 06 and live `14-computational-process-ontology.md` remain provenance.

## Argument

A world is not merely represented after the fact; it is continuously made determinate through operations. Distinction, exclusion, comparison, orientation, composition, recursion, satisfaction and return produce relatively stable things, judgments and actions from an inherited relational field. “Computational” names the rule-governed transformability of this process. It does not assert that reality is literally a digital computer or that executable syntax exhausts ontology.

The argument joins three levels without confusing them. Ontologically, process precedes the finished thing: an achieved entity is a stability inside relations and transformations. Epistemologically, knowing is one such process: a claim inherits sources, lenses, exclusions and revision conditions. Computationally, many of these transitions can be made explicit and repeatable in symbolic or technical systems. The third claim is useful precisely because the first two prevent computation from being mistaken for a sovereign machine-description of being.

Dia and Syn supply the runtime. Dia distinguishes, classifies, compares, ranks and selects. Syn preserves provenance, inverse reading, context and recomposition. Their failure modes are severance and fusion. In a technical system the same distinction can be inspected in prompt, retrieval, classifier, evaluator, memory, permission and action. A finished output ceases to be the entire epistemic object; the path by which it became determinate becomes first-class.

This is where QL and MEF acquire distinct offices. QL formalises positions and transformations; MEF runs a lens- and evidence-explicit inquiry across them. A Bimba Map can function as a locally governed reference field while remaining a revisable determination relative to wider worlds. Pratibimba names situated appearances/judgments relative to that local office. This recursive locality preserves `world ≠ world-model` and prevents technical inspectability from becoming metaphysical finality.
