## Argument

The torus is the primary kinetic image of the Arche-Topos because it can hold finite form, recurrent circulation, more than one independent winding, and an opening that is structurally internal to the surface's organisation. The claim is not that reality is literally toroidal. It is that the torus gives exact topological operations to a philosophical problem the essay has already derived: how can a traversal return without cancelling the difference accumulated through its path?

The quotient `T² = R²/Z²` supplies the crucial relation. An infinite plane covers a compact boundaryless surface; each torus-point has indefinitely many lifted representatives under the covering map. A finite address can therefore be exact while its covering field remains multiply articulated. The torus's fundamental group `Z × Z` records two independent winding directions. A rational-slope linear flow closes; an irrational-slope flow can wind densely. Recurrence and inexhaustible traversal are both native possibilities of the same surface.

The hole matters because return does not contract every path into one featureless centre. The opening is not an absent piece waiting to be filled; it participates in what the surface is. This makes the torus a disciplined neighbour for A03's immutable gap and A18's transverse Symbolon. A living return can circle a limit, cross changed positions and come back without pretending that origin and achieved return are simply the same event.

Music supplies the temporal analogue without becoming identical to topology. Repeated ratio can return by octave while retaining frequency difference; circle-of-fifths traversal can return with history and remainder. These homologies are valuable when their native mathematics stays distinct.
