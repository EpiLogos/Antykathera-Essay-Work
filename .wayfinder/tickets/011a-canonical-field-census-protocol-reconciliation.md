# Recensus the canonical field and reconcile publication protocols

## Question

Given the complete argument quilt, the now-current parallel harmonised quilt and the 48-coordinate traversal, what **actual argument/concept/root/path/publication field** does the completed quilt require — and which conflicting, duplicated or lost protocol clauses must be reconciled before that field can be ratified and built?

## Governing rule

Do not start from `21 arguments`, `22 concepts`, `4 paths`, the seven formerly proposed Symbolon root files, or any other historical count as if it were a target schema. Those numbers describe former repository state.

The eight stations with six internal positions remain the live coordinate scaffold unless the quilt itself forces a structural reconsideration. The present movement names/burdens inside that scaffold may be recomposed. Everything else is an open census governed by **distinct aletheia-work and return**, not quota.

The recovered `submission-package/essay/symbolon/episteme/concepts/reference-notes/` shelf is mandatory input. The repository records roughly ninety recovered notes there. They are not automatically ninety concepts; each nevertheless contains previously recovered material that must receive an explicit disposition.

## Mandatory reading

Read as one field, not as separate checklists:

- the complete current `27-07-26-QUILTING-FOR-FULL-ARGUMENT.md`, including every contribution after the 2026-08-02 parallel snapshot and especially the final 2026-08-18 Jung/Job/trust/monoisation/counterculture quilt;
- the complete current `2026-08-02-PARALLEL-HARMONISED-QUILT.md`, including all dated registrations/supersessions;
- `2026-08-03-PLAIN-ENGLISH-FULL-FLOW.md`;
- current central plan + orienting principles;
- the 48-movement Objective Internality traversal from ticket 011;
- all current argument nodes;
- all developed concept nodes **and every file in `concepts/reference-notes/`**;
- current root/Matheme/Mytheme/Episteme contracts and actual directory contents;
- all current paths/maps, histories, etymologies, dossiers, figures, dialogues, plates/media, source houses and technical/research fixtures that bear accepted material;
- `AGENTS.md`, `WRITING-PROTOCOL.md`, `docs/REPOSITORY-SHAPE.md` and every local skill/tool instruction that governs page creation/build/propagation.

Use effect maps where live records carry declared consumers. Do not infer that an old recovered note is obsolete because a developed concept happens to share some vocabulary.

## Pass D — protocol reconciliation

Create `PROTOCOL-RECONCILIATION.md` by comparing the actual governing layers:

1. `AGENTS.md` and central-plan authority rules;

For every conflict or duplication record: source A; source B; underlying intention of each; authority resolution; exact surviving rule; file(s) that must change now versus after T07.

### Fixed reconciliation: QL page form

The raw field-page template is:

```markdown
# <record title>

## #0

## #1

## #2

## #3

## #4

## #5→0
```

The six positions have **no globally fixed content semantics**. Do not hard-code `Definition`, `Operation`, `Pattern/Identity`, `Context`, `Quintessence`, or any equivalent universal headings. At creation time derive each position's local meaning from the record's operation, register, inherited/outgoing relations, and QL foundational qualities. Add descriptive subtitles only when earned.

The foundational qualities are validation/orientation constraints rather than template semantics. If a lower-level skill/tool contradicts this, repair the lower-level instruction.
