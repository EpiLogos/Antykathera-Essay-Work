# Definition of God — Working Folder Rules

Any session that drafts, revises, or extends prose in this folder is bound by the writing rubric:

**`/Users/admin/Documents/Nara-Personal/Antykathera-Essay-Work/writing-guidance-tools/WRITING-RUBRIC.md`**

Non-negotiable, before writing a word of essay prose:
1. Run the rubric's §0 pre-flight — including `authentic-voice-reference.md` §IV–V and the Cross-Cutting Patterns of `writing-style-reference.md` (same folder as the rubric), plus the three nearest paragraphs of Frank's own text.
2. Build the section dependency map (§0.4) before drafting: nothing asserted before the reader has been given the materials to read it.

Non-negotiable, after drafting:
3. Run the mechanical sweep (rubric §2).
4. Send every section to a fresh adversarial audit agent using the spawn-prompt in rubric §3. Revise until clean.
5. Ship with a ship-note: what moved, what was rewritten, kept grep-hits with justification, departures from any [F] annotation with reasons.

Frank's inline `[F]` blocks in draft files are ground-truth corrections — never delete or paraphrase them away; address them and record the resolution in the ship-note. His own edits to draft prose are register anchors: extend them, do not overwrite them.

Before proposing a revision or argument-level judgment, state internally: the author's declared proposition; its register; its local operation; its evidence task; any concrete tension; and the intervention constraint. A source can limit an attribution without downgrading the essay's own matheme, mytheme, or argued operation. Do not introduce a caveat that selects a safer neighbouring thesis. If there is a real fault, name it precisely: false attribution, material conflation, invalid inference, or an Open empirical question.

No prose ships from a single pass.
