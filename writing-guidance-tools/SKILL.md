# Writing Guidance Tools

Write from the argument outward. Use examples to judge prose that already exists, never to generate the argument or pre-shape its voice.

The bundled voice and fault examples are Frank Taylor-specific. For another author, preserve the laws, rubric, and load contract but replace both author-specific calibration files before using voice calibration.

## Scope includes canonical-field materialisation

Creating or rebuilding a canonical **Argument, Concept, Etymology, Symbolon, Matheme, Mytheme or Episteme record is philosophical writing**, even where the page also carries metadata, routing, backlinks or machine-readable fields.

A canonical record must therefore be recovered from its actual authored/developmental/source ground before its top-level prose is written. A census row, migration ledger, generated synopsis, current filename or graph position may locate the material; none may become the semantic source merely because it is compact.

For canonical-field work:

```text
recover whole / actual argument
→ determine the page's exact office
→ map claim, operation, dependencies and Return
→ write substantive top-level prose
→ add routing / metadata around that prose
→ audit against the rubric
```

Do **not** reverse this order by generating a page from fields and then filling its prose with a summary of those fields.

## Load Contract

Resolve all paths relative to this `SKILL.md`.

### Before the first argument draft or canonical philosophical record

Read only:

1. `references/WRITING-LAWS.md`
2. `references/WRITING-RUBRIC.md`
3. The project brief, sources, outline, existing essay text, and the actual authored/developmental carriers governing the record

Do **not** open:

- `references/fault-calibration.md`
- `references/authentic-voice-reference.md`
- `references/writing-style-reference.md`

Existing paragraphs from the essay are argument context, not calibration examples. If the essay has no prose yet, draft from its claims and sources; do not substitute a voice exemplar.

Map the section or record's claim, warrant, dependencies, operation, neighbouring relations, and intended conclusion/Return. Then draft the complete argumentative movement.

For a canonical Argument/Concept/Etymology record, explicitly ask before writing:

- What is this **here**, in the actual project field?
- Why does this distinction or argument exist?
- What relation gives it meaning?
- What does it do that neighbouring records do not?
- Which source or authored carrier presently determines that meaning?
- What detail will necessarily remain for later depth restoration, and where is the route back to it?

### First review

Keep all calibration files cold. Audit the draft independently against every gate in `references/WRITING-RUBRIC.md`.

Use a fresh reviewer or fresh context when available. If the drafting agent must also review, end the drafting pass first, restate the claim and dependency map without defending the prose, and begin a distinct audit pass.

For each fault, record:

`location · code · exact phrase · why it fails · repair direction`

Run the comparative and negation sweep from `references/comparative-and-negation-gate.md` during this audit: every `not X but Y`, corrective negative opener, and unnamed comparison must name a real position or operation whose difference carries weight.

Do not rewrite while finding faults. Do not use pattern matching, word counts, or regex hits as verdicts.

### Canonical-record anti-compression audit

For Argument/Concept/Etymology/Symbolon materialisation, additionally reject:

- census prose copied upward as if it were the whole argument;
- a list of related nouns standing in for the relation among them;
- source traditions averaged into a generic synthesis;
- a technical/framework name promoted into an Argument because it is prominent;
- etymological words promoted into Concepts merely because their archaeology is generative;
- a local section construct promoted into a whole-system Concept;
- QL labels used where the operation has not actually been followed;
- repeated redefinition of an already mature authored term instead of routing to its developed carrier;
- prose whose only achievement is to explain the page's taxonomy or metadata;
- machine-cadence summaries made of uniform `X is Y` sentences, slogan closers, or exhaustive-looking bullet inventories.

The record should carry enough top-level depth that a reader can understand the **actual distinction, derivation-pressure and consequence** before opening radial depth. Later Depth Restoration enriches it; it should not have to repair an empty administrative shell.

### Calibration review

Open calibration material only after the independent audit, and only to resolve a specific flag or judge a voice-sensitive repair:

- Use `references/fault-calibration.md` for the matching fault code.
- Use `references/authentic-voice-reference.md` for one named voice feature or edge.
- Use `references/writing-style-reference.md` for one relevant author, excerpt, or cross-cutting pattern.

Never read the whole style corpus by default. Locate headings first, then read the smallest relevant section. Calibration may confirm, reject, or refine a flag; it may not supply the essay's claim.

### Revision and release

Revise meaning before surface. Preserve earned complexity, deliberate rhythm, technical vocabulary that has been taught, and exceptions that can be explained. Re-audit changed paragraphs against all gates.

Return the revised prose. When useful, append a compact audit note naming material changes and any deliberate exceptions; do not expose internal process by default.

## Non-negotiable boundaries

- Rubric before examples.
- Argument before imitation.
- Retrieval before summary.
- Relation before taxonomy.
- Semantic judgment before mechanical signals.
- Selective calibration before corpus-wide reading.
- No sentence-length cap, vocabulary whitelist, passive-voice ban, or forced plainness.
- No invented quotations, missing-source reconstructions, or imitation of another author's surface manner.
- No later summary may silently supersede a richer original carrier.
- A canonical census or metadata schema is an identity/routing aid, never a semantic ceiling.
